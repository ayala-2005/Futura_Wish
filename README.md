# 🔮 FuturaWish

> **A JavaScript Learning Project** - Created while learning JavaScript fundamentals

An interactive e-commerce web application built with vanilla JavaScript, HTML, and CSS. FuturaWish allows users to browse products, manage shopping cart, and experience a complete online shopping flow.

🌐 **Live Demo**: [https://futura-wish.dermer.co.il/](https://futura-wish.dermer.co.il/)

## 📚 Learning Journey

This project was developed as part of my JavaScript learning journey. It represents hands-on practice with core JavaScript concepts through building a real-world e-commerce application including:
- DOM manipulation for dynamic product displays
- Event handling for user interactions
- Shopping cart functionality
- Form handling and validation
- Local storage for data persistence
- Interactive user experiences
- Modern JavaScript (ES6+) features

## 🌟 Project Overview

FuturaWish is a fully functional e-commerce web application built with vanilla JavaScript. The platform provides a complete online shopping experience with Hebrew interface (RTL support), allowing users to browse products, add items to cart, and complete their purchase journey.

### Key Pages
- 🏠 **Home Page** - Welcome page and featured products
- 📦 **Products** - Browse available items
- ℹ️ **About** - Information about the platform
- 🔐 **Login** - User authentication
- 🛒 **Shopping Cart** - Manage selected items

## 🛠️ Technology Stack

- **HTML5** - Structure and semantic markup
- **CSS3** - Styling and visual design (43.3% of codebase)
- **JavaScript** - Interactive functionality (43.5% of codebase)

## 🚀 Getting Started

### View Live Demo
Visit the live application at: **[https://futura-wish.dermer.co.il/](https://futura-wish.dermer.co.il/)**

### Run Locally

#### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Basic understanding of HTML/CSS/JavaScript (if you want to explore the code)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ayala-2005/Futura_Wish.git
```

2. Navigate to the project directory:
```bash
cd Futura_Wish
```

3. Open `index.html` in your web browser:
```bash
# On macOS
open index.html

# On Windows
start index.html

# On Linux
xdg-open index.html
```

Or simply drag and drop the `index.html` file into your browser.

## 📖 How to Use

1. **Browse Products**: Navigate to the products page to see available items
2. **Add to Cart**: Click on items to add them to your shopping cart

4. **Login**: Access the login page for user authentication
5. **Learn More**: Visit the About page for additional information
